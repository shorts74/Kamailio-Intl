Certificates

A Manager-owned registry for TLS certificates and SSH keys, pushed to nodes on demand. Web keeps using certbot's own auto-renewed certificate unless you nominate a different one here; HEP has no certificate nominated until you set one, which just means TLS mode isn't available for HEP yet -- nodes stay on plain UDP.

TLS Certificates
Read once at import time and stored from that point forward -- no ongoing dependency on this path after adding.
Self-signed, 10-year validity. Appropriate for internal-only traffic (HEP) where there's no public CA to verify against -- the cert's own signature becomes the trust anchor a node checks directly.
