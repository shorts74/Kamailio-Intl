The Manager-wide list of exposed Kamailio parameters, grouped by module. Per-node override values are set on each Node's own Settings page. Changing a default here affects any node without its own override -- takes effect on that node's next Apply & Restart. Looking for a module that isn't managed here yet? See the full Module Reference for every Kamailio module and what it does.

How module enable/disable actually works
A Kamailio module is active only if it has a loadmodule "name.so" line in the deployed kamailio.cfg -- there's no separate on/off switch, loading is enabling. Removing that line (and any modparam() calls that reference it) disables it; the module's functions simply become unavailable to the routing script. This platform currently loads a fixed set of modules the same way on every node (shown as "Loaded" below) -- per-node module toggling isn't available yet.
